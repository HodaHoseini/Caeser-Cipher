# Caeser-Cipher
Caesar Cipher

A simple Caesar Cipher program written in Python that can encrypt and decrypt text by shifting letters in the alphabet.

Features
Encode messages
Decode encrypted messages
Choose a custom shift value
Preserve characters that are not letters
Run multiple times without restarting the program

Technologies
Python
Python Concepts Practiced
Functions
Lists
Loops
Conditional statements
String manipulation
User input

How to Run

Make sure Python is installed on your computer.

python ceaser_cipher.py

Choose encode to encrypt a message or decode to decrypt one.

Then enter your message and the shift number.

Example
Message: hello
Shift: 5

Result: mjqqt

Purpose

This project was created to practice Python functions, loops, string manipulation, and basic encryption concepts.
